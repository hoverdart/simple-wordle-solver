    How to Use the Simple WORDLE Solver

    1. Enter a five-letter guess. Set green tiles where letters are correct.
    2. Set yellow tiles for letters in the wrong position.
    3. Leave absent letters gray. Repeated letters are handled separately.
    4. Click “Solve!” to find matching words. Add each guess to keep all your clues.
