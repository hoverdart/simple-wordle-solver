# Wordle Solver

An independent, browser-only aid for players already solving a five-letter game. Enter a guess and its feedback to narrow the candidate dictionary and rank useful next guesses. The original playable challenge and the separately sourced NYT answer index must not be confused.

A successful visit starts with the input or a suggested opener, maintains all earlier feedback, and finds a narrower set without accidentally revealing a daily answer. Preserve exact repeat-letter handling, keyboard input, undo/reset, daily publishing, archive, source and benchmark links, and static/browser-only computation. No affiliation with The New York Times.
